# Instalar Framer Motion

Para que el nuevo diseño del dashboard funcione con todas las animaciones, necesitas instalar framer-motion:

```bash
npm install framer-motion
```

O si usas yarn:

```bash
yarn add framer-motion
```

## Después de instalar:

1. Reinicia el servidor de desarrollo
2. Visita `/dashboard/new-page` para ver el nuevo diseño
3. Si todo funciona bien, reemplaza el dashboard actual

## Si no quieres usar animaciones:

He creado versiones alternativas sin framer-motion en los archivos con sufijo `-static.tsx`
