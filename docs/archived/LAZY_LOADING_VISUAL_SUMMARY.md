## 🎯 Uso Rápido

### 1️⃣ Importar

```typescript
import { LazyWrapper, ReportCharts } from '@/components/lazy'
```

### 2️⃣ Envolver

```typescript
<LazyWrapper>
  <ReportCharts data={data} />
</LazyWrapper>
```

### 3️⃣ ¡Listo! 🎉

```
El componente ahora se carga solo cuando se necesita
```
