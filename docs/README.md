## 📝 Convenciones

### Nomenclatura de Archivos
- `FEATURE_NAME.md` - Documentación de features
- `QUICK_START_*.md` - Guías de inicio rápido
- `SETUP_*.md` - Guías de configuración
- `*_COMPLETE.md` - Features completadas (archived)
- `*_SUMMARY.md` - Resúmenes (archived)

### Estructura de Documentos
Cada documento debe incluir:
1. Título descriptivo
2. Descripción breve
3. Contenido organizado
4. Ejemplos de código (si aplica)
5. Referencias a otros documentos

## 🔄 Mantenimiento

### Actualizar Documentación
1. Mantener documentos actualizados con cambios
2. Mover documentos completados a `archived/`
3. Actualizar este índice cuando se agreguen nuevos documentos
4. Eliminar documentación obsoleta

### Agregar Nueva Documentación
1. Crear documento en la carpeta apropiada
